## 拥堵凝滞二次修复：软体人群（2026-10-04 19:50）
- 用户复测截图：速度正常了，但漏斗口仍拱形堵塞。根因在物理层：单位间硬碰撞的接触冲量会把"顶住前方单位"的法向速度清零，压力沿人群传播→全体冻结。上一轮的 35% 前进保底只是速度意图，会被接触冲量吃掉。
- **方案：软体人群模式**（三件套）：
  1. `UnitBase.SoftBodyCrowd` 静态开关（两个 Bootstrap 的 Start 里置 true）：单位挪到 Ignore Raycast 层 + `Physics2D.IgnoreLayerCollision(layer, layer, true)`——单位间不再硬碰撞，与 Default 层的墙仍硬碰撞；
  2. `CdtNavigationSystem.ResolveOverlaps()`：LateUpdate（静态帧号守卫每帧一次）做 2 轮松弛式位置去重叠，允许重叠到双方半径和的 45%，超出部分按质量加权各推一半——位置修正不清零速度；
  3. 分离力加"同向流动折扣"（对方与自己同向时分离需求 ×0.35~1.0），排队链收紧成流。新增 `UnitBase.CurrentVelocity`、`NavigationCollisionRadius`、`MovementMass` 属性。
