# Desert Storm Unit Lab（团结引擎迁移版）

本项目使用团结引擎 1.6.13 创建，目标是将 Godot 版本的《沙漠风暴》单位、伤害测试和寻路原型迁移到团结/Unity 兼容工作流中。

## 运行

1. 使用团结引擎 1.6.13 打开本目录。
2. 打开 `Assets/Scenes/DesertStorm.unity`。
3. 点击 Play 运行测试场景。

需要单独观察寻路机制时，打开 `Assets/Scenes/NavigationDemo.unity`。该场景会用三条不同起点和终点的路径展示障碍绕行与路径收束。

## 当前内容

- `DesertStormBootstrap.cs`：运行时生成整体测试场景、障碍物、训练假人和极简几何单位；提供左侧单位生成面板与右侧独立伤害统计面板。
- `UnitCatalog.cs` / `UnitData.cs`：三大阵营单位数据与基础数值。
- `UnitBase.cs`：单位移动、刚体碰撞、攻击、伤害事件和冲击性质量。
- `CdtNavigationSystem.cs`：解耦的 CDT 风格障碍约束可见性图、A* 最短路径、路径收束和动态单位避让服务。
- `CameraPanController.cs`：WASD 摄像头移动、鼠标滚轮高度缩放、中键/空格拖拽。
- `TrainingDummy.cs`：伤害测试假人及累计伤害/命中统计。

## 测试操作

- 左侧先选择阵营和单位，再设置本次生成数量，点击“生成单位（仅本次）”。
- “随机生成 5 种不同单位”每次生成五个不同单位。
- “清空单位”和“重置假人”用于重新开始测试。
- 左侧面板可用 Tab 隐藏，也可单独调整 UI 缩放；右侧伤害统计面板同样可以独立隐藏和缩放。
- 单位遇到障碍物会沿导航网绕行；同阵营单位相遇时，冲击性较低者绕行，冲击性较高或相等者尝试挤开前方单位。

## 说明

当前迁移版使用运行时生成的颜色块和圆形精灵，便于个人团队先验证玩法、数值和寻路，再替换为正式美术资源。寻路实现是面向原型的 CDT 风格可见性图版本，保留了后续替换为更完整动态 CDT/漏斗实现的解耦边界。
